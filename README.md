# 未來學院 Prompt 庫（Future Elite Academy）

我是 Mr Patrick，Future Elite Academy 創辦人。本庫收錄的，全部是我和團隊每天真正在使用的 prompt——不是收集回來的清單，而是完成工作、驗證過後才放上來的實戰資產。每條均註明用途、所需輸入、輸出成果，以及我們的試用評語。

使用方法很簡單：按分類進入，複製整條 prompt，換上你自己業務的資料即可使用。
