# 001｜一個月內容計劃

- **分類**：內容生產
- **狀態**：未試（未試跑前不可標「已試」）
- **來源**：FEA 原創《一個月內容計劃》——**定稿原文待 Patrick／林雪提供後補入**（本檔暫為結構骨架，不含未經確認的內容）

## 用途

為一盤細生意排出**一個月**可以照住做嘅內容計劃：揀咗乜題目、每星期出幾多、用咩格式、點樣接到銷售。

## 要入咩（輸入）

- 生意類型同主打服務
- 目標客戶（畫像、痛點、常見問題）
- 每月可投入嘅時間／人手／預算
- 想推嘅嘢（服務、活動、產品）
- 現有素材（客戶故事、FAQ、舊文、產品資料）
- 想加強嘅渠道（網站、IG、LinkedIn、email、搜尋）

## 出咩（輸出）

- 一個月內容行事曆（週次／日期／渠道／格式／題目／一句 hook）
- 每條內容嘅重點大綱（不用寫全文，方便各人自己執）
- 對應嘅銷售用途（邊條為邊個客群、推邊個服務）
- 每週一個可量度指標（睇乜數、幾時覆盤）

## 試用評語

- 尚未試跑（按新規則，Patrick 或林雪試跑一次並記低結果之後，先可以改標「已試」）。
- 試跑後請補：邊個生意試咗、卡喺邊、邊句 prompt 要改、改完效果如何。
